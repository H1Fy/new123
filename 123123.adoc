= Лекция 1. Среда разработки программ для микроконтроллера
:author: Апанович Семен


== Введение

В лекции рассматривается интегрированная среда разработки (IDE)
*IAR Embedded Workbench for Arm*, которая используется для создания
программ для микроконтроллеров.

Компания IAR предлагает две бесплатные версии:

* *Evaluation* — полный функционал, но ограничение 30 дней;
* *Kickstart (KS)* — ограничение размера кода 32 Кбайт, но без ограничения по времени.

Для студенческих задач версии Kickstart более чем достаточно.

== Процесс создания программы

Создание исполняемого файла состоит из двух этапов:

. *Трансляция* — компилятор превращает исходный код C++ в объектные файлы.
. *Компоновка* — линковщик собирает объектные файлы и библиотеки в один исполняемый файл (ELF).

После этого файл можно загрузить в симулятор или прошить в микроконтроллер.

== Запуск программы до main()

До вызова функции `main()` микроконтроллер выполняет несколько шагов:

. Инициализация указателя стека.
. Обнуление неинициализированных глобальных переменных.
. Копирование начальных значений инициализированных переменных из ПЗУ в ОЗУ.
. Вызов `main()`.

Эти действия описываются в файле `cstartup.cpp`.

== Настройка проекта

Основные шаги при создании проекта:

. Создать новый проект: *Project ⇒ Create New Project*.
. Выбрать шаблон *C++ — main*.
. Выбрать микроконтроллер: *ST ⇒ STM32F4 ⇒ STM32F411 ⇒ ST STM32F411RE*.
. Настроить размер стека (STACK) и кучи (HEAP) в настройках линкера.
. Для отладки на реальной плате выбрать драйвер *ST-Link*.

== Пример программы

Ниже приведён пример программы, которая поочерёдно включает и выключает
светодиоды на портах A и C микроконтроллера STM32F411RE.

[source, cpp, linenums]
----
#include "rccregisters.hpp"   // for RCC
#include "gpioaregisters.hpp" // for GPIOA
#include "gpiocregisters.hpp" // for GPIOC

std::uint32_t SystemCoreClock = 16'000'000U;

extern "C" {
int __low_level_init(void)
{
  // Включить внутренний 16 МГц генератор
  RCC::CR::HSION::On::Set();
  while (RCC::CR::HSIRDY::NotReady::IsSet())
  {
  }

  // Переключить системную тактовую частоту на HSI
  RCC::CFGR::SW::Hsi::Set();
  while (!RCC::CFGR::SWS::Hsi::IsSet())
  {
  }

  RCC::APB2ENR::SYSCFGEN::Enable::Set();

  return 1;
}
}

void delay(int cycles)
{
  for (int i = 0; i < cycles; ++i)
  {
    asm volatile("");
  }
}

int main()
{
  // Подать тактирование на порт A
  RCC::AHB1ENR::GPIOAEN::Enable::Set();
  // Подать тактирование на порт C
  RCC::AHB1ENR::GPIOCEN::Enable::Set();

  // Порт A.5 на вывод
  GPIOA::MODER::MODER5::Output::Set();
  // Порты C.5, C.8, C.9 на вывод
  GPIOC::MODER::MODER5::Output::Set();
  GPIOC::MODER::MODER8::Output::Set();
  GPIOC::MODER::MODER9::Output::Set();

  for (;;)
  {
    GPIOC::ODR::ODR5::High::Set();
    delay(1000000);
    GPIOC::ODR::ODR8::High::Set();
    delay(1000000);
    GPIOC::ODR::ODR9::High::Set();
    delay(1000000);
    GPIOA::ODR::ODR5::High::Set();
    delay(1000000);

    GPIOC::ODR::ODR5::Low::Set();
    delay(1000000);
    GPIOC::ODR::ODR8::Low::Set();
    delay(1000000);
    GPIOC::ODR::ODR9::Low::Set();
    delay(1000000);
    GPIOA::ODR::ODR5::Low::Set();
    delay(1000000);
  }

  return 1;
}
----

== Пояснение к программе

* В функции `__low_level_init()` выполняется начальная инициализация:
  включается внутренний генератор HSI и настраивается системная тактовая частота.
* Функция `delay()` создаёт простую задержку с помощью пустого цикла.
* В `main()` сначала подаётся тактирование на порты A и C,
  затем нужные выводы настраиваются как выходы.
* В бесконечном цикле светодиоды поочерёдно зажигаются и гаснут.
